# 설문 / 폼 빌더 예제

- `/surveys`: 객관식, 1~5점 척도, 텍스트 질문을 구성하고 순서를 변경한다. 초안을 발행하면 질문이 고정되며 응답 작성과 결과 확인이 가능하다. 마감 후에는 추가 응답을 받지 않는다.

React Hook Form과 Zod로 입력을 검증한다. 모델은 각 feature의 `model`에, 재사용 화면은 `components`에, 라우트 진입점은 `pages`에 둔다.

페이지는 상태와 이벤트를 연결한다. 설문 목록과 상태별 작업은 `SurveyList`, `SurveyHeader`가 담당한다. `model/index.ts`는 외부 소비용 스키마와 타입을 명시적으로 공개하며, 내부 코드는 구현 파일을 직접 참조한다. 페이지 진입점은 화면별 `pages/<page>/index.ts`를 유지한다.

브라우저 로컬 데모이며 서버 전송이나 다중 사용자 동기화를 제공하지 않는다. 브라우저 데이터 삭제 시 기록도 지워진다. 설문은 최대 100개, 질문은 설문당 30개, 응답은 설문당 1,000개다. 저장 데이터를 읽을 수 없으면 원본을 덮어쓰지 않고 변경을 중단한다.

검증은 모델·화면·저장 실패 테스트와 `e2e/surveys.e2e.ts`에서 수행한다. 화면 상태를 Storybook에서 확인할 수 있다.
