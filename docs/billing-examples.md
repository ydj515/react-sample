# 인보이스 예제

로그인 후 워크스페이스 메뉴에서 `/billing`에 접근합니다.

`/billing`은 상태별 목록, `/billing/$invoiceId`는 공유 가능한 상세 경로입니다.
해당 브라우저에 저장된 송장만 조회할 수 있습니다.
React Hook Form과 Zod로 고객·기한·세율·라인 아이템을 검증합니다.
KRW 정수 단가와 정수 수량을 곱해 소계를 구하고, 소계에 세율을 적용한 뒤
원 단위 반올림으로 세금을 계산합니다. 라인 아이템은 최대 100개입니다.
합계 계산은 항목 수 n에 대해 시간 O(n), 추가 공간 O(1)입니다.

초안은 수정·발행·취소할 수 있고, 발행 후에는 결제 완료 또는 취소만 가능합니다.
결제 완료와 취소는 최종 상태입니다. 인쇄 버튼은 브라우저 인쇄 창을 열고
인쇄 CSS는 앱 메뉴를 숨겨 송장만 출력합니다.
`react-sample-billing-v1`에 저장하는 로컬 데모이며 서버 API, 결제, 이메일 발송,
법적 세금계산서 기능은 포함하지 않습니다.

저장소 읽기 실패 시 원본 덮어쓰기를 중단하고 오류를 알립니다.
저장 공간 초과 시 입력을 유지하고 실패를 표시합니다. 브라우저 저장소 삭제 시
데이터가 사라지며, 탭 간 동시 편집·사용자별 분리·서버 동기화는 지원하지 않습니다.

## 검증

모델 테스트는 금액·입력 제한·상태 전이를, 컴포넌트와 페이지 테스트는
라인 아이템 폼, 송장 발행·결제와 저장 실패를 확인합니다. `e2e/billing.e2e.ts`는
송장 발행·결제 흐름, 인쇄 매체와 모바일 너비를 검증합니다.
