# 노트 / 마크다운 에디터 예제

로그인 후 워크스페이스 메뉴에서 `/notes`에 접근합니다.

제목·본문·쉼표 구분 태그를 편집하고 제목 또는 태그로 검색합니다.
미리보기는 즉시 갱신하고 마지막 입력 500ms 후 `react-sample-notes-v1`에 저장합니다.
저장 완료 표시를 확인하고 페이지를 떠나세요. 새로고침 시 저장한 노트를 복원합니다.
최대 100개 노트, 제목 100자, 본문 100,000자, 태그 입력 300자를 지원합니다.

기존 CMS의 안전한 Markdown 렌더러를 공개 API로 재사용합니다.
제목·목록·인용·굵게·링크·인라인 코드와 fenced code를 지원하며 HTML은 실행하지 않습니다.
JS/TS/JSON 코드의 문자열·키워드·숫자·주석을 간단한 토큰 기반으로 강조합니다.
전체 CommonMark 문법이나 완전한 언어 파서는 지원하지 않습니다.

저장소 읽기 실패 시 원본 덮어쓰기를 중단하고 오류를 알립니다.
저장 공간 초과 시 입력을 유지하고 실패를 표시합니다. 브라우저 저장소 삭제 시
데이터가 사라지며, 탭 간 동시 편집·사용자별 분리·서버 동기화는 지원하지 않습니다.

## 검증

모델 테스트는 입력 제한을, 컴포넌트와 페이지 테스트는 미리보기·복원과 저장 실패를 확인합니다.
`e2e/notes.e2e.ts`는 브라우저 저장·검색·복원과 모바일 너비를 검증합니다.
