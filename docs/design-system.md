# 디자인 시스템

로그인 화면, 사이드바, GNB, 대시보드와 프로젝트 화면은
`src/app/styles/index.css`의 의미 기반 토큰을 공유합니다.
라이트·다크 모드는 같은 토큰의 값만 바꿉니다.

## 색상

| 역할      | 유틸리티                                              | 사용처                          |
| --------- | ----------------------------------------------------- | ------------------------------- |
| 작업 배경 | `bg-canvas`                                           | 페이지 바탕                     |
| 기본 표면 | `bg-surface`                                          | 사이드바, GNB, 카드, 다이얼로그 |
| 보조 표면 | `bg-surface-muted`                                    | 표 헤더, 보조 영역              |
| 경계      | `border-line`, `border-line-strong`                   | 영역 구분, 입력창               |
| 텍스트    | `text-ink`, `text-ink-muted`, `text-ink-subtle`       | 제목, 본문, 보조 문구           |
| 강조      | `bg-brand text-on-brand`                              | 주요 버튼, 브랜드               |
| 선택      | `bg-brand-soft text-brand`                            | 현재 메뉴, 선택 필터            |
| 상태      | `positive`, `caution`, `negative`, `info` 및 `*-soft` | 상태 배지, 안내, 차트           |

차트와 활동 표시에는 `chart-positive`, `chart-caution`, `chart-negative`의
선명한 색상을 사용합니다. 작은 상태 글자는 대비를 유지하는 기존 상태 토큰을
사용합니다. 카드 그림자는 `shadow-panel`로 공유합니다.

개별 페이지에서 `bg-indigo-600`, `text-slate-500` 같은 팔레트 값으로
공통 컴포넌트를 덮어쓰지 않습니다. 차트도 같은 토큰을 사용하며,
라벨과 데이터 표로 색상 외의 구분 수단을 제공합니다.

## 크기와 간격

- 페이지 제목: `PageHeader`의 24px 제목, 14px 설명, 8px 사이 간격.
- 본문·컨트롤: 기본 14px, 보조 정보·배지 12px, KPI 숫자 28px.
- 컨트롤: 높이 40px, Compact 36px, `rounded-control` 8px.
- 카드: `rounded-panel` 12px, 1px 경계, 기본 내부 여백 20px.
- 페이지: 영역 간격 24px, 카드 그리드 간격 16px, 모바일 좌우 여백 16px.
- 셸: 사이드바 256px, 로고 영역과 GNB 높이 64px, Compact 56px.
- 모바일 서랍의 바깥 모서리는 0px입니다. 일반 다이얼로그는 12px을 유지합니다.
- 1024px 미만에서는 높이 64px과 기기 안전 영역을 반영한 고정 하단 메뉴를 표시합니다.
  본문·알림·스크롤 여백도 하단 메뉴 높이에 맞춥니다.
- 데스크톱 푸터는 본문 다음에 배치하며, 짧은 페이지에서는 화면 하단에 놓입니다.
- 메뉴·입력·버튼의 키보드 포커스는 강조색을 사용합니다.

## 공통 컴포넌트

`cn`의 Tailwind 병합 설정에는 `control`, `panel` 모서리 토큰을 등록해
`rounded-none` 같은 표준 유틸리티로 안전하게 덮어쓸 수 있게 합니다.

`Button`, `Input`, `Select`, `Card`, `Badge`, `PageHeader`를 재사용합니다.
상태 배지는 프로젝트와 주문 화면 모두 `Badge`를 사용합니다.
새 화면은 `PageHeader`와 카드 조합에서 시작하고, 도메인별 데이터와
상호작용을 feature 내부에 둡니다.

Storybook의 `Layouts/DesignSystem`에서 셸과 공통 컴포넌트를 함께
확인할 수 있습니다. Theme·Density 툴바로 테마와 밀도를 전환합니다.
각 컴포넌트 스토리에서도 같은 토큰이 적용됩니다.

검증은 `pnpm verify`로 실행합니다. E2E는 로그인 후 사이드바·GNB의
표면 일치, 검색·이동, 390px·1280px 레이아웃, 테마 전환을 확인합니다.

## 목록 화면 공통 규칙

- `Pagination`: 대시보드 주문 검색, 사용자·주문·상품 관리, 프로젝트 목록이
  같은 컴포넌트를 사용합니다. 왼쪽에는 조회 범위·전체 건수·현재 페이지,
  오른쪽에는 이전·숫자·다음 버튼을 표시합니다. 숫자는 최대 5개만 표시하며
  현재 페이지를 `aria-current`로 알립니다. 빈 목록도 0건과 비활성 이동 버튼을 유지합니다.
- 기본 페이지 크기는 8건입니다. 검색·필터·정렬이 바뀌면 1페이지로 돌아갑니다.
  대시보드 주문 검색은 페이지 변경 시 선택 주문을 해제합니다.
- `FilterBar`와 `FilterField`: 검색·필터는 16px 카드 여백, 12px 항목 간격,
  12px 라벨과 8px 라벨 간격을 공유합니다. 모바일 검색창은 전체 너비를 사용하고
  나머지 필터는 다음 줄로 배치합니다. 초기화는 보조 버튼으로 표시합니다.
- `SearchInput`: 목록 검색에 같은 검색 아이콘, 왼쪽 여백, 입력 높이를 사용합니다.
  GNB 빠른 이동은 별도 다이얼로그를 여는 버튼이므로 목록 입력창과 구분합니다.
- `CollectionTable`: 관리 목록·대시보드 주문·리포트 표가 헤더 배경, 경계,
  가로 16px/본문 세로 16px 여백과 행 호버를 공유합니다. 표 너비는 기본 720px,
  열이 적은 리포트는 520px이며 작은 화면에서는 표 안에서 가로 스크롤합니다.
- `EmptyState`, `QueryFeedback`: 빈 결과의 안내·초기화, 로딩 및 오류 재시도는
  공통 컴포넌트를 사용합니다. 프로젝트 목록도 같은 흐름을 따릅니다.
- 상태 색상은 도메인 배지에서 결정합니다. `OrderStatusBadge`와
  `UserStatusBadge`를 목록·상세에 함께 사용하여 같은 상태의 색상이 달라지지 않게 합니다.
- 이동 링크를 버튼처럼 표시할 때는 `Button asChild`를 사용합니다.
  페이지에서 별도의 버튼 높이·색상·모서리 스타일을 만들지 않습니다.

검색 결과·페이지 이동·초기화의 동작은 단위/통합 테스트로 확인하며,
브라우저 테스트는 390px·1280px에서 공통 페이지 버튼, 검색창 높이,
표 셀 여백과 가로 넘침 여부를 비교합니다.

### Icon 버튼과 밀도

`Button size="icon"`은 일반 모드에서 40px, compact 모드에서 36px이며 두 모드 모두 패딩은 0입니다. compact 기본 패딩을 icon 크기에서 명시적으로 덮어써 내부 `size-4` 아이콘이 16px을 유지하도록 합니다. `Shared/UI/Button/CompactIcon` 스토리와 탐색 E2E에서 이 조합을 확인합니다.
