# 랜딩 페이지 예제

## 진입 경로

관리자 사이드바의 **샘플 → Landing Pages** 또는 `/landing`에서
로그인 없이 세 가지 랜딩을 탐색한다.

| 경로              | 목적                 | 주요 구성                                             |
| ----------------- | -------------------- | ----------------------------------------------------- |
| `/landing`        | 샘플 선택            | 랜딩 카드, Docs·쇼핑·관리자 연결                      |
| `/landing/saas`   | SaaS 제품 소개       | 보드 미리보기, 기능, 워크플로우, 요금제, FAQ          |
| `/landing/course` | 온라인 강의 소개     | 공개 수업, 학습 목표, 커리큘럼, 강사, 수강권, FAQ     |
| `/landing/agency` | 디자인 스튜디오 소개 | 작업 필터, 사례 상세, 프로세스, 서비스, 프로젝트 문의 |

## 구성과 재사용

`src/routes/landing.*.tsx`는 페이지 연결만 담당한다.
페이지는 `src/features/landing/pages/{saas,course,agency}`에서 자신의
헤더, 본문 순서, 푸터를 조합한다. 모든 화면을 하나의 variant 기반
레이아웃으로 묶지 않는다.

- `LandingContainer`: 콘텐츠 너비와 좌우 여백
- `LandingSection`: 섹션 간격과 고정 헤더를 고려한 앵커 여백
- `LandingPage`: 문서 제목과 본문 건너뛰기 링크
- `LandingMenu`: Radix Dialog 기반 모바일 메뉴, 닫기·Escape·포커스 복귀
- `LandingFaq`: 키보드로 조작할 수 있는 네이티브 details/summary
- `InquiryForm`, `InquiryDialog`: 공통 데모 입력 검증과 완료 안내

이 컴포넌트들은 랜딩 feature 내부에서 재사용한다. 전역 색상·타이포·버튼·
입력·테마 컨트롤은 기존 디자인 시스템을 사용하며, 별도 라이브러리나
전역 CSS 덮어쓰기를 추가하지 않는다.

## 상호작용과 상태

- SaaS: 월간·연간 전환은 로컬 상태다. 연간은 월간 금액의 20% 할인,
  월 환산 금액 × 12를 연간 합계로 표시한다. 신청 창에는 선택한
  플랜과 주기의 합계를 전달한다. 새로고침하면 월간으로 돌아간다.
- 강의: 4개 챕터·12개 수업·총 5시간의 가상 구성이다. 첫 수업은
  영상 대신 텍스트와 코드로 제공한다. 수강권 신청에 플랜과 금액을 표시한다.
- 에이전시: 4개 가상 프로젝트를 분야별로 필터하고 상세 다이얼로그에서
  문제와 접근 방식을 읽는다. 필터는 새로고침 시 전체로 돌아간다.
- 섹션 이동은 URL hash를 사용하며 직접 접근과 새로고침을 지원한다.
- 문의·신청은 React Hook Form과 Zod로 이름·이메일·문의 내용을 검증한다.
  입력값을 API, 이메일 또는 로컬 스토리지로 전송·저장하지 않는다.
  완료 안내는 현재 컴포넌트에만 유지하며 다시 작성 시 입력을 초기화한다.

모든 브랜드, 강사, 요금과 포트폴리오는 가상 콘텐츠다. 실제 계정 생성,
구독, 결제, 수강 등록 또는 프로젝트 문의 접수는 구현하지 않는다.

## 확인과 검증

Storybook의 `Pages/Landing`에 컬렉션과 3종 랜딩의 기본·모바일·다크
스토리를 제공한다. `Features/Landing`에서는 요금 전환, 필터, 미리보기,
FAQ와 폼의 오류·완료 상태를 확인한다.

단위·컴포넌트 테스트는 가격 계산, 입력 검증, 화면 이동, 선택 결과와
다이얼로그 동작을 검증한다. `e2e/landing.e2e.ts`는 390px·1440px에서
모바일 메뉴, 앵커/새로고침, 테마, 신청과 탐색 흐름을 검증한다.
최종 검증 명령은 `mise exec -- pnpm verify`다.
