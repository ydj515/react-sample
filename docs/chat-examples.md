# 메시징 / 채팅 예제

`/chat`: 상향 페이지네이션, 낙관적 전송과 재시도, 읽음, 입력 중 표시

얇은 route는 각 feature의 `pages/<page>/index.ts`만 소비합니다. UI는
`components/`에 분리하고 `model/index.ts`는 명명된 계약만 공개합니다.
모델은 Zod 스키마와 순수 함수로 구성합니다. 페이지 헤더가 메타데이터를 설정합니다.

## 두 탭으로 채팅 체험

같은 브라우저 프로필에서 `/chat`을 두 탭으로 열고 참여자를 각각 민아와 준으로
선택합니다. 메시지와 읽음은 localStorage에 저장하고 BroadcastChannel로
변경을 전달합니다. 지원하지 않는 환경에서는 storage 이벤트로 메시지와
읽음을 동기화하며 입력 중 표시는 제공하지 않습니다.

외부 서버, 실제 사용자 인증, 다른 기기 사이 통신을 구현한 메신저는 아닙니다.
전송은 600ms 지연으로 서버 응답을 모사하며 `다음 전송 실패 체험`을 선택하면
실패 후 동일한 메시지 ID로 재시도할 수 있습니다. 실패한 전송은 메모리에만
남으므로 새로고침 전 재시도해야 합니다. 확정 메시지는 메시지별 저장 키를
사용하여 서로 다른 두 메시지의 동시 전송이 목록을 덮어쓰지 않습니다.

과거 예제 대화 60개를 20개씩 불러옵니다. 위로 스크롤하면 이전 페이지를
추가하고 기존 화면 위치를 유지합니다. 실제 저장소 읽기는 전체 로컬 메시지를
검증한 뒤 페이지를 선택하므로 대규모 서버 페이지네이션의 대체재는 아닙니다.
읽음은 창에 포커스가 있고 최신 메시지까지 내려간 경우에만 갱신합니다.
입력 중 상태는 입력 중단 신호 또는 3초 만료로 사라집니다.

저장소 접근과 탭 간 전송은 feature의 `data/chat-repository.ts`에 둡니다.
손상된 저장 데이터를 읽으면 원본 보호를 위해 새 전송을 막습니다.

## 검증

모델 테스트는 메시지 중복 제거를, 페이지 테스트는 실패 재시도를, 저장소 테스트는 동시 전송·재시도·읽음 단조 증가를 검증합니다.
`e2e/chat.e2e.ts`는 두 탭의 왕복 전송과 읽음·입력 중 상태, 상향 스크롤, 새로고침 복원 및 모바일 너비를 검증합니다. Storybook에는 채팅 전송 상태를 제공합니다.
