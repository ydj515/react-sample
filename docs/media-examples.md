# 파일 관리자 / 미디어 라이브러리

로그인 뒤 `/files`에서 폴더 탐색, 폴더 생성, 파일 검색, 업로드,
이미지·텍스트 미리보기와 다운로드를 사용할 수 있다.

## 폴더와 검색

폴더는 `parentId`로 중첩된다. 왼쪽 폴더 트리와 상단 경로 버튼은 같은
`folder` URL search를 변경한다. 루트의 **전체 파일**은 모든 폴더의 파일을
보여주며, 폴더를 선택하면 해당 폴더에 직접 속한 파일만 보여준다.
검색어 `q`는 현재 범위의 파일명에 적용한다.

폴더 생성은 현재 폴더 아래에 수행한다. 전체 파일 화면에서는 루트 폴더가
생성된다. 같은 상위 폴더의 중복 이름은 409이며 잘못된 상위 폴더는 404다.
없는 폴더 URL은 오류와 전체 파일 복귀 버튼을 표시하고 업로드를 막는다.

## 업로드·미리보기

- 파일 선택과 드래그&드롭 모두 다중 파일을 지원한다.
- PNG, JPEG, WebP, TXT, Markdown만 허용한다. HTML/SVG 등은 제외한다.
- 빈 파일과 파일당 5MB 초과 파일은 클라이언트와 mock API 양쪽에서 거절한다.
- `FormData`로 실제 파일과 `folderId`를 전송한다. multipart boundary는
  브라우저가 설정하므로 Content-Type을 직접 지정하지 않는다.
- 파일은 순차 업로드한다. 진행 중 중복 업로드를 막고 성공/실패를 파일별로
  표시한다. 일부 실패가 다른 파일의 성공을 취소하지 않는다.
- 업로드가 시작된 폴더를 대상으로 저장한다. 실행 중 폴더를 이동해도 대상은 바뀌지 않는다.
- 이미지는 img로, 텍스트는 UTF-8 텍스트로 표시한다. 텍스트/Markdown의 HTML은 실행하지 않는다.
- 미리보기 대화상자는 닫을 수 있고 다운로드 링크를 제공한다.

## API와 저장 한계

| 메서드·경로                  | 응답                         |
| ---------------------------- | ---------------------------- |
| `GET /api/media`             | 폴더와 파일 메타데이터       |
| `POST /api/media/folders`    | 생성한 폴더, 201             |
| `POST /api/media/files`      | 업로드 메타데이터, 201       |
| `GET /api/media/:id/content` | 허용 MIME type과 base64 내용 |

MSW 핸들러는 파일 내용을 메모리에 저장한다. 서버 파일시스템이나 클라우드에
저장하지 않으며 새로고침하면 업로드 자료가 사라진다. 테스트마다 초기화한다.
미리보기 내용의 쿼리 캐시는 대화상자 종료 후 제거한다(`gcTime: 0`).
이 예제의 MIME 검사는 파일 형식 선언 검사이며 실제 서버의 파일 시그니처 검사나
영속 저장을 대체하지 않는다. 대용량 스트리밍·업로드 재개·폴더 이동·삭제는 포함하지 않는다.

## 검증

`pnpm exec vitest run src/features/media`로 크기·형식·경로 조건,
폴더 생성과 중복, multipart API, 미리보기와 검색을 검증한다.
`pnpm exec playwright test e2e/media.e2e.ts`로 실제 파일 선택·드래그,
이미지/텍스트 미리보기와 390px 화면을 확인한다.
Storybook `Features/Media/FolderTree`는 중첩 폴더를 보여준다.
