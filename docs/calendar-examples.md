# 캘린더 / 일정 예제

`/calendar`: 월·주·일 보기, 일정 CRUD, 드래그 이동, 시간 충돌 감지

얇은 route는 각 feature의 `pages/<page>/index.ts`만 소비합니다. UI는
`components/`에 분리하고 `model/index.ts`는 명명된 계약만 공개합니다.
모델은 Zod 스키마와 순수 함수로 구성합니다. 페이지 헤더가 메타데이터를 설정합니다.

## 캘린더 날짜와 충돌 규칙

서울 시간(UTC+9)의 날짜·시간 문자열을 저장하고 고정 오프셋의 민간 시간으로
계산합니다. 호스트 컴퓨터의 시간대나 서머타임을 계산에 섞지 않습니다.
월 보기는 월요일부터 42칸, 주 보기는 월요일부터 7일, 일 보기는 24시간입니다.
월·주 보기는 작은 화면에서 캘린더 내부를 가로 스크롤합니다.

일정 손잡이로 날짜를 옮기고 주·일 보기에서는 시간 칸으로 옮깁니다. 이동 시
소요 시간을 보존합니다. 분 단위 입력은 일정 수정 폼에서 지원합니다.
여러 날에 걸친 일정은 각 날짜에 표시합니다. 시간대 셀은 시작 시각을 기준으로
카드를 배치하며 카드 높이가 일정 길이에 비례하는 타임라인은 아닙니다.

충돌은 `[시작, 종료)` 구간으로 판정합니다. 종료와 다음 시작이 같으면 허용하고
수정 대상 자신은 제외합니다. 충돌하는 생성·수정·드래그는 저장하지 않고
기존 일정을 보존합니다. 종료가 시작보다 늦어야 하며 잘못된 날짜도 거부합니다.

캘린더는 공통 `useLocalRecords`로 저장 성공 후 화면을 갱신하며 읽기 실패 시
원본을 보호합니다. API를 사용하지 않으므로 API/Query/MSW 계층은 만들지 않습니다.

## 검증

모델 테스트는 윤년, 월·연 경계, 자정 이동, 인접 구간과 자기 자신 제외를 검증합니다. 페이지 테스트는 CRUD를 검증합니다.
`e2e/calendar.e2e.ts`는 드래그 이동, 충돌, 새로고침 복원 및 모바일 너비를 검증합니다. Storybook에는 캘린더 보기·폼 오류 상태를 제공합니다.
