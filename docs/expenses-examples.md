# 가계부 예제

- `/expenses`: 원화 수입·지출을 등록하고 수정한다. 월, 유형, 카테고리, 메모 검색에 일치하는 내역으로 합계와 카테고리별·일별 차트를 계산한다. 저장 후에는 해당 거래 월의 전체 유형으로 필터를 전환한다.

React Hook Form과 Zod로 입력을 검증한다. 모델은 각 feature의 `model`에, 재사용 화면은 `components`에, 라우트 진입점은 `pages`에 둔다.

페이지는 상태와 이벤트를 연결한다. 필터·합계·내역은 `ExpenseFilters`, `ExpenseSummary`, `ExpenseList`가 담당한다. `model/index.ts`는 외부 소비용 스키마와 타입을 명시적으로 공개하며, 내부 코드는 구현 파일을 직접 참조한다. 페이지 진입점은 화면별 `pages/<page>/index.ts`를 유지한다.

브라우저 로컬 데모이며 서버 전송이나 다중 사용자 동기화를 제공하지 않는다. 브라우저 데이터 삭제 시 기록도 지워진다. 거래는 최대 10,000건이며 금액은 1~10억 원의 정수다. 저장 데이터를 읽을 수 없으면 원본을 덮어쓰지 않고 변경을 중단한다.

검증은 모델·화면·저장 실패 테스트와 `e2e/expenses.e2e.ts`에서 수행한다. 화면 상태를 Storybook에서 확인할 수 있다.
